# auor.io

The most comprehensive [x402][] API collection.

[auor.io][] (pronounced Oreo), makes available multiple APIs through the [x402][] standard. Meaning you can call any API available with no signup required, and no API keys  required. Just call the API and get the information you need.

For information on which API endpoints are available, or for more technical information, have a look at the [documentation][].

[auor.io]: https://auor.io
[documentation]: https://auor-io.gitbook.io/docs
[x402]: https://www.x402.org/
