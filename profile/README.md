# auor.io

> [x402][] AI agent research toolkit

[auor.io][] (Oreo), makes multiple APIs available through the [x402][] standard. Meaning you can call any API available with no signup required, and no API keys required. Just call the API and get the information you need.

For information on which API endpoints are available, or for more technical information, have a look at the [documentation][].

[auor.io]: https://auor.io
[documentation]: https://auorio.gitbook.io/docs
[x402]: https://www.x402.org/
